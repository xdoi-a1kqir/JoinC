## web-reduce

In the project directory, you can run:

### `npm run eject`

**One-way operation.** Exposes all config and dependencies for full control. Cannot be undone.

### `npm run lint`

Reports style errors and warnings.

### `npm run format`

Auto-formats source files.

### `npm start`

Runs in development mode. Open [http://localhost:3420](http://localhost:3420). Hot reload enabled.
